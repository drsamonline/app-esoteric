Esoteric

A cross-cultural dictionary of symbols. The same symbol in two cultures is two entries, each attributed and each sourced.

Open Esoteric

This app does not tell you what a symbol means. It shows you what traditions have made of it, and where that was read.

Status Built and working offline: a bundled dictionary where every entry names its tradition and its source; search that returns entries from more than one tradition and says so; a search with no match that says so with the terms used and offers no nearby symbol; and your own notes, with a note on an unknown symbol kept as unsorted rather than filed under the wrong one.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: a complete dictionary. The bundle is a starter set of seven symbols and seventeen entries, each attributed to a named reference work — and the app says to check the source rather than repeat it.

What it does

  • Looks up a symbol across traditions, one entry per tradition, each with its source.
  • Says when more than one tradition reads the same symbol — which is the point.
  • Keeps your notes against a symbol, or as unsorted if the symbol is not in the bundle.
  • Works with no network at all: the entries are bundled, and nothing is fetched.

What it will not do

  • Give a single meaning. Meanings are attributed and sourced, never asserted.
  • Offer a nearby symbol as the one you asked for. A near miss shown as an answer is worse than nothing.
  • File a note under a symbol it does not have. It is kept as unsorted.
  • Lose the dictionary to a broken note file. The bundled entries are read-only.

When things go wrong

CaseWhat happens
Bad inputNo match → said with the terms used, no nearby symbol offered. A note with no text → refused.
No networkNothing changes; the entries are bundled.
Storage full or unavailableThe note is not saved and the app says so; reading and search continue from the bundle.
Corrupt saved stateThe note file is reported and offered for export; the bundled entries cannot be corrupted by use.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js.
